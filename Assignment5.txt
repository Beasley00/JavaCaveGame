In this project, I researched the switch statement, which is a control flow structure in Java used to execute a specific block of code out of multiple possible options. It appears in 2 places in Main. It first appears inside the combat loop to process the player's battle action (Attack, Defend, or Potion). It also appears again at the end of the round to process the chosen reward. A switch statement checks a single variable and matches it against different case values. This is very useful because it provides a much cleaner and readable alternative to writing long if-else statements. The program also uses the break keyword to stop the code from executing the other cases under the matched cases.
